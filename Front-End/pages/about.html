About
Geek Hub

Geek Hub is a personal project built to practice C# Web API development and modern front-end techniques. It's my very first back-end project.

The goal is to build a modern and minimalist wiki for characters, giving each one a unique visual identity and immersive presentation instead of plain, boring text.

The back-end is powered by ASP.NET Core with Entity Framework Core and SQLite, exposing a REST API. The front-end is built with HTML, Tailwind CSS and vanilla JavaScript.
